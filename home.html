Core Capabilities

Built for the
full stack reality

From REST endpoints to WebSocket frames, from JWT tokens to GraphQL mutations — Phantoma handles every layer of your stack.

Real-time Capture
Intercept all HTTPS traffic instantly. Color-coded methods, inline smart tags, live filter bar — everything at a glance.
Capture · Filter · Inspect
Breakpoints
Halt requests mid-flight. Edit headers, body, method — then forward or drop. Full in-flight control with the Composer editor.
Intercept · Edit · Forward
Security Audit
Automatic passive scanning of every request. Detects API key exposure, JWT leaks, weak CORS, missing security headers — instantly.
HIGH · MED · LOW severity
WebSocket Inspector
Live WSS message streams with direction indicators, timestamps, and manual frame injection. Watch every ping, pong, and payload.
WSS · Frame Injection · Live
Auto Responder
Mock any endpoint with local files or redirect to staging. Custom status codes, artificial delays, drag-and-drop response files.
Mock · Redirect · Delay
Match & Replace
Regex-based traffic rewriter. Inject debug headers, swap auth tokens, rewrite body JSON — on every request automatically.
Regex · Headers · Body · URL
